# Minimal example

A fully filled copy of the charter, the escalation rules, and the coder role.
The values come from `placeholders.json` (a made-up project named `example-trading`, owned by Alice). This is not a real trading system.

Copy `TEAM_CHARTER.md`, `ESCALATION_ADR.md`, and `AGENTS.md` into a project root and change the names, paths, and commands to match that project.

These three files are generated by `scripts/generate_templates.py`. Edit `placeholders.json` or the role files in `roles/`, then regenerate. Do not edit the filled copies by hand.
